The short version

If you only read one thing on this page, read the note. The rest of the guide is the long way round to the same four lines.

In short

  • A product feed is a shop's whole range as one list. One row per product: name, price, picture, link.
  • You get it from your affiliate network. As a link to the list or as a file, for each shop that has accepted you.
  • A plugin reads the list for you. You search it inside WordPress and pick products instead of copying them.
  • A link stays current, a file does not. A link can be read again every night. A file stays as it was the day you saved it.

What is in a feed

Every online shop keeps a list of what it sells. To let affiliates work with that list, the shop shares it in a form a program can read. That shared list is the product feed.

It is not a web page, and you will rarely open it yourself. Think of a very long spreadsheet: one row for each product, one column for each thing the shop knows about it.

Product feedA shop's whole range as one list, shared with its affiliates. Some networks call it a data feed or a product catalogue.

One row, one product

A row carries what a reader needs to decide: the product's name, the brand, today's price, the old price if there is a sale, and a picture.

It also carries the one thing you need: your affiliate link for exactly that product. A feed is not a list of things to link to later. The links are already in it.

Where you get it

Shops do not hand their feed to everyone. You join a shop's affiliate programme through an affiliate network, and once the shop has accepted you, the network gives you access to its feed.

Some networks give you a link: a web address the list can be read from at any time. Others give you a file to download. Both hold the same rows.

A link beats a file. A link can be read again every night, so prices keep up with the shop. A file stays exactly as it was on the day you downloaded it.

A reader asks

“Do I have to understand CSV or XML to use one?”

No. Those are only the formats the list is saved in. A plugin that reads feeds deals with the format. You deal with the products.

Questions people ask

The ones that come up before a first feed.

Is a product feed the same as an affiliate link?

No. An affiliate link points to one product. A feed is the list of all of a shop's products, and every row has its own affiliate link in it.

That is why a feed saves the copying: the link for a product is already there the moment you pick it.

Does every shop have a product feed?

No. A shop decides whether it shares one with its affiliates.

Most networks show it on the shop's programme page or in their own section for feeds. If you cannot find it, the shop's affiliate contact can tell you.

How often does a feed change?

That is up to the shop. Many update their list once a day, some more often.

What matters on your side is how often it is read. A feed link can be fetched again every night. A downloaded file is read once.
