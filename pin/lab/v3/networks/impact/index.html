Before you start

A feed pays off when you want many products from one shop, with picture and price. For two or three, a normal Impact link in your text is enough. How a shop's product feed gets into WordPress explains the idea.

  • You work with the shopImpact lists product catalogs only for brands you partner with. Brand is Impact's word for a shop.
  • The shop has opened its catalogEach brand decides whether you see a catalog, and how you may fetch it.
  • MyFeeds is in your WordPressNot installed yet? The install guide takes you through it.

Step 1 of 2

Download the file in Impact

GoalThe shop's products as one file on your computer, in Impact Format.

  1. Set the file type once

    Impact currently keeps it behind your profile icon: Settings, then Data Feeds in the Technical section, then Edit next to Product Feed.

    Choose CSV, the type a spreadsheet can open if you ever want to check a row.

  2. Open the shop's product catalog

    Impact currently lists catalogs under Content, then Product Catalogs.

    Menus move. If it is gone, see Impact's own walkthrough: Download product catalogs as a partner.

  3. Download it in Impact Format

    Impact offers two versions. Advertiser Format is the file as the shop uploaded it, with fields that differ from shop to shop. Impact Format has the same fields every time. Take that one.

    The download ends in .gz. Upload it as it is: MyFeeds opens it, up to 500 MB.

  4. Keep the file to yourself

    It shows what you earn. The file holds your tracking links and a field called ProductBid: what a sale of each product pays you. Don't share it or store it in a public folder. MyFeeds keeps your upload on your own site, under a random file name.

You have the file. On to step 2

Step 2 of 2

Upload the file in WordPress

The first time

Upload the file

  1. In WordPress, open MyFeeds and click Add your first feed.
  2. Name the feed after the shop: readers see that name on your cards. Choose Upload a file and select the file you downloaded.
  3. Click Create Feed and let it import in the background. The feed's row shows the number of products.
  • Prices and stock freeze on upload day, until you upload a newer file.
When the shop's prices have moved

Upload a newer file

  1. Download the catalog again in Impact.
  2. On the feed's row in MyFeeds, click Edit and select the new file.
  3. Click Save Changes, then Reimport.
  • Your published cards follow the newer file. You don't edit the posts.

Check the first import. We have not tested a current Impact file from end to end. Search for a product in the editor and check picture, price and link. If a column landed in the wrong place, correct it in the Mapping Editor.

What the file contains

Five fields worth knowing, as Impact's help names them.

Fields of an Impact Format file and what they are
Field in the fileWhat it is
Current PriceWhat a customer pays now
Original PriceThe price before a reduction
Stock AvailabilityWhether the shop has it in stock
Product URLYour tracking link to the product
ProductBidWhat you get for a sale. Keep it private.

Names can differ. The first row of your file may spell these fields another way.

A file from someone else earns for them. The tracking links belong to the account that downloaded the file.

Questions about Impact catalogs

For anything else, write to us.

Why is there no catalog for a shop I work with?

The shop has not switched catalogs on, has limited them to certain partners, or offers no download in the browser.

All three are the shop's choice, Impact's help says. Ask the shop to open the catalog for you.

Is there a link in place of the download?

Not one MyFeeds can read. Impact documents three ways to get a catalog: the download in your browser, FTP and an API for programmers (as of October 2026). The last two ask for a login, which MyFeeds cannot give.

If each new file lands at an https address on your own server, MyFeeds reads that address every night. Anyone who has the address can read the file too, and it shows what you earn.

More questions

How often does a catalog change?

Impact asks brands to update their catalog daily. Last Updated shows when a shop last did.

Can I see which post and product a click came from?

ProFrom the Pro plan, yes: clicks on your cards are counted by post and product. In the feed dialog, under Advanced Options, set Network Hint to Impact.com, when you add the feed or later through Edit. Your affiliate links then also get a click ID in subId1, a field Impact reports back.

Impact shows it under Reports, More Reports, in Performance by Sub ID and Shared ID. Its help says only you see Sub IDs, not the shop.
