Before you start

The first file can take up to 24 hours, so subscribe today and import tomorrow. For two or three products, a FlexOffers link in your text is enough. How a shop's product feed gets into WordPress explains the idea.

  • The shop's programme has approved youPre-approved programmes are often processed within 5 business days. Restricted ones can take 2 weeks or more (as of October 2026).
  • A traffic source in your accountFlexOffers' name for the website you promote on. You pick it when you subscribe.
  • MyFeeds is in your WordPressOur plugin for the WordPress block editor. If it is not installed yet, the install guide takes you through it.

Step 1 of 2

Subscribe to the feed in FlexOffers

GoalThe shop's product feed as a file on your computer.

  1. Open the place for feed subscriptions

    This is where you choose which shops' products FlexOffers prepares for you. It is currently under Flex Apps, then Product Feeds. Click + Select A Feed.

    Product feeds, not promotional feeds. FlexOffers has both. Promotional feeds hold deals and coupon codes, no products.

    Menus move. If it is gone, see FlexOffers' own walkthrough: Data Feeds - Subscriptions.

  2. Set up the subscription

    Choose your traffic source and name the subscription. Pick XML or CSV: MyFeeds reads both. Then click Get Advertisers.

  3. Tick the shop and save

    FlexOffers calls shops advertisers. Hover over the shop's Health Check entry for details about its feed, then tick the shop and click Save.

    Keep to one shop per subscription: in MyFeeds a feed carries one shop's name, and readers see it on every card.

  4. Fetch the file the next day

    By FTP. The login details are near the top of the same page. If no password is shown, click Generate. You need an FTP program: FlexOffers suggests FileZilla.

    As a download. FlexOffers' release notes (2022, 2024) also describe an https link to the same feed, compressed. The later note puts those links in the export of your subscription list. MyFeeds opens .zip and .gz files as they are.

    1. FlexOfferssends a new file every day, after 10 pm Eastern time.
    2. Your computerYou fetch it by FTP or as a download.
    3. MyFeedsYou upload it. Your cards show that day's prices.

You have the file. On to step 2

Step 2 of 2

Add the file in WordPress

GoalThe shop's products in WordPress, ready to search in the editor.
Start here

Upload the file

  1. In WordPress, open MyFeeds and click Add your first feed. On a paid plan, later feeds go through + Add Feed.
  2. Name the feed after the shop: readers see that name on your cards. Choose Upload a file, pick the file and click Create Feed.
  3. Let it import. It runs in the background while you keep working.
  • A file stays as it was on upload day. For new prices, fetch the newer file, click Edit on the feed's row, choose it and save, then click Reimport.
If you use the download

Try its link first

MyFeeds can read a link only if it opens without a login. We couldn't confirm that this one does, or that it stays the same. Open it in a private browser window.

  • The download starts: paste the link under At a URL. MyFeeds then reads it again every night.
  • A login page appears: MyFeeds can't read it. Upload the file instead.

The shop's products are in. Publish your first cards

Check one link before you publish

FlexOffers' help doesn't say whether the links in the file are your tracking links.

Take one product link from the file and compare it with a FlexOffers link for the same shop. Yours are in the Links menu, under Link Search.

  • Both start the same way: the links in the file are tracked.
  • The file's link starts with the shop's own address: it is a plain link. A reader can buy through it and you get no commission.

With plain links, ask FlexOffers support for a feed with tracking.

Questions about FlexOffers feeds

For anything else, write to us.

I subscribed and there is no file. Is something wrong?

Probably not. FlexOffers allows up to 24 hours before the first file is there.

Why is the shop missing from the advertiser list?

Check that its programme has approved you, then remove the category and country filters in the subscription.

FlexOffers shows where you stand with each shop in the Advertisers menu: approved, pending review, declined or not applied.

More questions

Can MyFeeds fetch the file from the FTP server for me?

No. MyFeeds reads https links and uploaded files.

If you can put the daily file at an https address of your own, paste that address under At a URL and MyFeeds reads it every night.

Can I see which post and product a click came from?

ProFrom the Pro plan, yes: clicks on your cards are counted by post and product. With Network Hint set to FlexOffers under Advanced Options, your affiliate links also get a click ID in fobs, the first sub ID field in FlexOffers' reports.
